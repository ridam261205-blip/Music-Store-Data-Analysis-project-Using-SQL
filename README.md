# 🎵 MUSIC STORE DATA ANALYSIS USING SQL

---

## 🌟 **📌 PROJECT OVERVIEW**
This project focuses on analyzing a Music Store database using SQL to extract meaningful business insights.  
By querying relational data, the project answers real-world questions related to sales performance, customer behavior, popular artists, and revenue trends.

This project represents my hands-on learning journey in SQL and data analysis using a real-world dataset.

---

## 🎯 **OBJECTIVES**
- Analyze customer purchasing behavior  
- Identify top-selling artists and genres  
- Understand revenue distribution across countries  
- Practice advanced SQL concepts on a real dataset  
- Convert raw data into actionable business insights  

---

## 🗂️ **DATASET INFORMATION**
- **Dataset Name:** Music Store Database  
- **Type:** Relational Database  
- **Tables Used:**  
  `customer`, `invoice`, `invoice_line`, `track`, `album`, `artist`, `genre`

---

## 🛠️ **TOOLS & TECHNOLOGIES**
- **Database:** PostgreSQL  
- **Query Tool:** pgAdmin  
- **Language:** SQL  

---

## 📊 **SQL CONCEPTS USED**
- SELECT statements  
- INNER JOIN & multiple table joins  
- GROUP BY & HAVING clauses  
- Aggregate functions (SUM, COUNT, AVG)  
- Subqueries  
- ORDER BY & filtering techniques  

---

## ❓ **BUSINESS QUESTIONS ANSWERED**
- Which artist generated the highest revenue?  
- How much did each customer spend on artists?  
- What are the most popular music genres?  
- Which country contributes the most to total sales?  
- Who are the top customers based on spending?  

---

---

## 🚀 **HOW TO RUN THIS PROJECT**
1. Download and install PostgreSQL  
2. Import the Music Store Database  
3. Open pgAdmin  
4. Load `SQL Database questions - easy, moderate, advanced` in Query Tool  
5. Execute queries to view results
